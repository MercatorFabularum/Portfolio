Graphic Design Work

This is a collection of my graphic design work, laid out to betted show off mockups.

Logo

This project was the new logo for my website and personal brand. I mocked it up on a package, to show what it could be used for if I ever started selling tangible products

"Parlor Tricks" Book Cover Design

This project was creating a book cover; since this was for a class the book is not a real, published thing. I chose to make a sci-fi / cyberpunk inspired cover for a book about a tatoo artist with a "magical" tatoo needle gun, set in the near future, with lots of time in a grungy underground.

The illustrations are all drawn by me, and I assembled the piece in InDesign.

"Ocean of Magnolias" Mixtape

This project was custom packaging for a casette of the "Ocean of Magnolias" original score. I was helping develop this game, and wanted to have a marketable and fun item for promoting the game.

The mockup shows off the product, which is a small cabin "box" that can unfold to reveal various panels showcasing inspiration photos, sketches, and screenshots. It also has a "book" box of the casette itself, which is designed with the digital OST cover photo, as well as some of the tree art from the game.
